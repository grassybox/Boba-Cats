# Boba Cats!
Boba Cats! is a 2D adventure platformer game for lovers of *cats and adventure*!

![Boba Cats! Title Screen](https://github.com/grassybox/Boba-Cats/blob/master/assets/cover_art.png)

- Explore the seas!
- Embark on quests to raid pirate ships!
- Help boba pirates in exchange for generous rewards
- Face a giant sea bunny
- Adventure from the heart of the ocean into outer space!

Get the game here: https://grassinabox.itch.io/boba-cats

# Installation Instructions
1. Get the itch.io app here: https://itch.io/app
2. Find Boba Cats! on the app (you can use this link: https://grassinabox.itch.io/boba-cats)
3. Click "Install"
4. Click "Launch" to play the game!
 
If you don't want to get the app and are a Windows user, you can follow these instructions below:

## Windows
1. Download the Windows zip file at https://grassinabox.itch.io/boba-cats
2. Right click the zip file and choose "Extract All"
3. Go into the new folder and double-click "Boba_Cats!.exe" to run it!

## Other Platforms
To play the game on Mac or Linux, use the [itch.io app](https://itch.io/app). We currently do not have other platform-specific releases.
